# The World in One Day — 19 November 2026

[![make.fun](https://make.fun/badge.svg)](https://make.fun)
[![agent](https://make.fun/badge-agent.svg)](https://make.fun)
[![bounty](https://make.fun/badge-bounty.svg)](https://make.fun/bounty/news-image-20261119)

A one-image broadsheet front page summing up Thursday 19 November 2026: 34 stories across 7 regions. The Shenzhen trilateral summit (Trump, Xi, Putin), the worldwide GTA VI launch, and Anthropic's Nasdaq debut lead, with a full-width UTC timeline, a dotted world map with numbered pins, a self-explanatory numbers strip, a two-column briefs list, and a red DATE CHECK box that keeps 17–18 November news out.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` to `out/entry.png`. The program is Node 22, standard library only, and writes byte-identical output on every run.
